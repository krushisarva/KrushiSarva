# KrushiSarva Seller: Google Play Console answers

Package name: `com.krushisarva.seller` · Written 15 October 2026 against the code in this folder. Updated 28 October 2026 to match the final privacy policy.

## How to use this file

- Go top to bottom. Each heading below is one page in Play Console.
- Text in a grey box is ready to paste. Copy the whole box.
- **Bold** words are the exact option to click.
- `<PLACEHOLDER ...>` means you fill it in yourself. There are only two kinds: the test phone number and its code.
- Do **Part 1** first. After that, Play Console's **Dashboard** shows a list of set-up tasks with a link to each one. Parts 2 and 3 can be done in any order. Part 3 follows the order of that Dashboard list.
- Character counts are counted the strict way, one per letter and one per vowel sign, so Play's own counter will show the same number or a smaller one.
- This is a **separate app** in Play Console from the farmer app, with its own listing, its own forms, its own 12 testers and its own 14 days. The farmer app's answers are in `farmer-app.md`.

**Before this works you must build the demo shop.** A new account opens on the business profile form and cannot sell until the KrushiSarva team verifies it, so Google's reviewer would be stuck there. On your own phone:

1. Add the seller test number in Firebase (Part 5, item 4) and sign in to the Seller app with it.
2. Fill in the business profile: a display name, business type **Krushi Kendra** and a Maharashtra location (district, taluka, village) in the **same district as the farmer test account**. That type and district are what let the farmer app's "send this scan report to a Kendra" find the demo shop. Tick "I don't have a GST number" unless the demo shop really has one. Leave the bank account, Aadhaar and PAN empty: the form does not require them, and the admin panel can verify the shop without them (step 4). Google's reviewer can open this form, and the app shows back the Aadhaar and account numbers with their last 4 digits, the PAN (Permanent Account Number) with its first 5 and last 2 characters, and the GST (Goods and Services Tax) number, IFSC (Indian Financial System Code), bank name and account holder name in full. Never type a made-up Aadhaar or PAN number; the app checks them.
3. Tick the consent box and **Save**.
4. In the admin panel (https://krushi-sarva.vercel.app) → **KYC / Sellers** → set **Status** to **PENDING** (the page opens on SUBMITTED, and a shop with no Aadhaar or PAN stays PENDING) → open the demo shop → **Verify**.
5. Back in the app: add 2 or 3 products (Add product → search the catalogue → price, stock, photo) and one delivery area (Profile → Delivery areas) that includes the PIN code of the farmer test account. The catalogue on the new server is most likely empty, so each search will find nothing and the app will offer to add the product as new. A new product waits for review: admin panel → **Catalog QC** → approve each one, or farmers never see it.
6. With the farmer test account, place one cash-on-delivery order from this shop, so the reviewer sees an order on the Orders screen.

#### Who receives the data, and why every "Shared" answer is No

Google's rule: sending data to a company that **only does a job for you, under your instructions**, is not "sharing". These are all such "service providers":

| Company | What it does | What it receives from this app |
|---|---|---|
| Google Firebase | Sign-in by text-message code; delivering notifications | Phone number, app and device identifiers, IP address |
| Expo | Sending notifications and app updates | Notification token, notification text, app version, internet (IP, Internet Protocol) address |
| Cloudinary | Storing product photos | Product photos |
| India Post | Filling in the area from a PIN (Postal Index Number) code | The PIN code only |
| Hostinger | Runs the server | Everything stored on the server |

**Why this app has no "Shared" ticks when the farmer app has seven.** The farmer app's ticks come from Google's free Gemini service, which may use what it receives for Google's own products. The Seller app sends nothing to Gemini, Groq, Sarvam AI or any other AI company: it only shows crop reports that farmers already made in the farmer app (checked in the code on 28 October 2026).
